# نقشه راه «حرفه‌ای‌تر شدن» هاوڕێ

این فهرست بر اساس **بیشترین تأثیر به کم‌ترین هزینه** مرتب شده و همهٔ محدودیت‌های پروژه را رعایت می‌کند
(بدون پرداخت، بدون تبلیغات، فقط ایمیل و Google برای ورود).

---

## ✅ گام ۰ — چیزهایی که همین حالا اضافه شد

| قابلیت | چرا حرفه‌ای‌تر می‌کند |
|---|---|
| **نشان پیام خوانده‌نشده** روی «آشنایی‌ها» (هدر و نوار پایین، به‌روزرسانی هر ۲۰ ثانیه) | کاربر بدون باز کردن صفحه می‌فهمد پیام دارد |
| **PWA کامل** (`manifest.ts`) | روی موبایل «افزودن به صفحه اصلی» می‌شود و مثل اپ مستقل باز می‌شود |
| **صفحه خطای اختصاصی** (`error.tsx`) با کد پیگیری و دکمه تلاش دوباره | به‌جای صفحه سفید، تجربه‌ای قابل‌اعتماد |
| **اسکلت بارگذاری سراسری** (`loading.tsx`) | جابه‌جایی بین صفحات بدون پرش و سفیدی |
| **`robots.ts` + `sitemap.ts`** | کنترل دقیق ایندکس؛ صفحات خصوصی هرگز ایندکس نمی‌شوند |
| **تصویر اشتراک‌گذاری (OG image)** | لینک سایت در واتساپ/تلگرام با کارت زیبا نمایش داده می‌شود |
| **CI در GitHub Actions** (`.github/workflows/ci.yml`) | هر Push: typecheck، lint، build و ساخت ایمیج داکر |

## ✅ گام ۱ — بستهٔ «تجربه کاربری» (انجام شد)

1. ✅ **حالت تاریک (Dark Mode)** — سوییچ سه‌حالته (روشن/سیستم/تاریک) در تنظیمات، دکمه سریع در هدر، بدون پرش رنگ هنگام بارگذاری.
2. ✅ **وضعیت «آنلاین / آخرین بازدید»** و **نشانگر «در حال نوشتن…»** در چت — با احترام به تنظیم حریم خصوصی کاربر.
3. ✅ **فیلترهای کاوش**: بازه سنی، شهر و علاقه‌مندی مشترک.

## ۱) اولویت بالا — ادامه تجربه کاربری
1. **تجربه اولین ورود**: نوار پیشرفت تکمیل پروفایل («پروفایل شما ۶۰٪ کامل است») + راهنمای کوتاه سه‌مرحله‌ای.
5. **Toast یکپارچه** برای همه پیام‌های موفقیت/خطا به‌جای Alertهای درون‌صفحه‌ای.
6. **صفحه ۴۰۴ و حالت‌های خالی غنی‌تر** با پیشنهاد اقدام بعدی.

## ۲) اولویت بالا — اعتماد و ایمنی (۲ تا ۴ روز)

7. ✅ **تأیید هویت سبک** — انجام شد: سلفی ژست‌دار + بررسی دستی مدیر + حذف خودکار تصویر پس از بررسی.
8. **صف مدیریت گزارش‌ها**: اقدام‌های یک‌کلیکی (هشدار، تعلیق موقت، حذف عکس) + تاریخچه اقدام‌ها.
9. **فیلتر خودکار متن**: تشخیص شماره تلفن/لینک/کلمات توهین‌آمیز در پیام‌ها و بیو، با علامت‌گذاری برای مدیر.
10. **مرکز امنیت کاربر**: نمایش نشست‌های فعال، خروج از همه دستگاه‌ها، تاریخچه ورود.
11. **صفحه «نکات ایمنی قرار اول»** پیش از شروع گفت‌وگو.

## ۳) اولویت متوسط — کیفیت فنی (۱ تا ۳ روز)

12. ✅ **ارسال واقعی ایمیل** با Resend + چهار قالب HTML فارسی — انجام شد.
13. **ردیابی خطا با Sentry** (پلن رایگان) + **لاگ ساختاریافته** با pino.
14. **تست‌های خودکار در CI**: اجرای `smoke-test` و Playwright روی هر Pull Request.
15. **بکاپ خودکار روزانه** با cron + آپلود رمزنگاری‌شده روی Object Storage.
16. **Redis برای Rate Limit و Cache** (به‌جای جدول دیتابیس) هنگام رشد.
17. **Realtime واقعی** با SSE یا WebSocket به‌جای Polling هشت‌ثانیه‌ای.

## ۴) اولویت متوسط — رشد و محتوا

18. ✅ **چندزبانه‌سازی (i18n)** — انجام شد: فارسی، کردی سۆرانی، عربی و انگلیسی با تغییر خودکار جهت صفحه.
19. **صفحه «درباره ما» و وبلاگ ساده** برای اعتماد و SEO.
20. **دعوت دوستان** با لینک اختصاصی (بدون جایزه مالی).
21. **آمار داخلی حریم‌محور** (Umami یا Plausible self-hosted) به‌جای Google Analytics.

## ۵) بلندمدت

22. اپ موبایل بومی (React Native) با همان API.
23. اعلان Push مرورگر برای پیام‌های جدید.
24. مهاجرت به PostgreSQL + اجرای چندنمونه‌ای پشت Load Balancer.
25. داشبورد سلامت سرویس (Uptime، تأخیر، خطاها) برای مدیر.
