# لیست خرید و راه‌اندازی — از ایران، با کمترین هزینه 🇮🇷

هدف: سرویس واقعی و پایدار برای **حدود ۱۰۰ کاربر در ماه**، با کمترین هزینهٔ ممکن.

> **خلاصه هزینه: ماهی ۷۰۰ تا ۸۰۰ هزار تومان** (سرور) **+ سالی حدود ۳ میلیون تومان** (دامنه).
> اگر بتوانید ارزی پرداخت کنید، سرور به **سالی ~۱۲ دلار** می‌رسد (یعنی ماهی ~۱۰۰ هزار تومان).

## ۳) ایمیل (رایگان)

برنامه حالا **هم SMTP و هم Resend** را پشتیبانی می‌کند، پس هر کدام که برایتان در دسترس بود:

### الف) Gmail با «رمز اپلیکیشن» — رایگان، ساده، ۵۰۰ ایمیل در روز ⭐
1. در حساب گوگل خود **تأیید دو مرحله‌ای** را روشن کنید
2. به [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) بروید و یک **App Password** بسازید
3. در `.env.production` بگذارید:
```bash
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"
SMTP_USER="you@gmail.com"
SMTP_PASS="رمز-اپلیکیشن-۱۶-رقمی"
MAIL_FROM="هاوڕێ <you@gmail.com>"
```

### ب) Zoho Mail — رایگان با دامنهٔ خودتان
[zoho.com/mail](https://www.zoho.com/mail/) → پلن Forever Free → `SMTP_HOST="smtp.zoho.com"`

### ج) Resend — فقط اگر پرداخت/دسترسی ارزی دارید
[resend.com](https://resend.com) — ۳٬۰۰۰ ایمیل در ماه رایگان. از ایران معمولاً قابل ثبت‌نام نیست.

## 📋 ترتیب دقیق کارها

1. **سرور بخرید** (گزینهٔ الف، ۱ گیگ رم، Ubuntu 24.04) → یک **IP** و یک **رمز root** تحویل می‌گیرید
2. **دامنه بخرید** → در پنل دامنه، رکورد **A** بسازید: `@` و `www` → IP سرور
3. از گوشی با **Termux** یا **JuiceSSH** به سرور وصل شوید:
   ```bash
   ssh root@IP-سرور
   ```
4. سه دستور:
   ```bash
   apt update && apt install -y git
   git clone https://github.com/matinpar/hawre.git && cd hawre
   bash deploy.sh yourdomain.com you@email.com
   ```
5. رمز مدیری که چاپ می‌شود را ذخیره کنید
6. ایمیل Gmail را طبق بخش ۳ در `.env.production` بگذارید و `docker compose up -d`
7. تمام ✅ — `https://yourdomain.com`

## ⚖️ نکتهٔ حقوقی (مهم)

در ایران، سرویس‌های آشنایی و همسریابی تنها با **مجوز رسمی** مجاز هستند و فعالیت بدون مجوز می‌تواند پیامد قانونی داشته باشد. پیش از انتشار عمومی:

- سرور و دامنه را **خارج از ایران** بگیرید (دیتاسنتر داخلی و دامنهٔ `.ir` نیازمند ساماندهی و مجوز است و ارائه‌دهنده ممکن است سرویس را قطع کند)
- اگر مخاطب هدف شما خارج از ایران است (مثلاً اقلیم کردستان عراق)، قوانین همان کشور را بررسی کنید
- در صورت نیاز با یک مشاور حقوقی محلی مشورت کنید

این پروژه از نظر فنی کامل و امن است؛ تصمیم دربارهٔ انتشار و قوانین محلی با خود شماست.
