# اجرای پروژه کامل هاوڕێ فقط با گوشی 📱

سه راه وجود دارد. **راه ۱ ساده‌ترین و سریع‌ترین است.**

---

## 🥇 راه ۱ — Replit (پیشنهاد اول)

**چرا؟** اپ رسمی اندروید/آیفون دارد، نیازی به نصب چیزی روی گوشی نیست، پروژه روی سرور آن‌ها اجرا می‌شود و یک **لینک دائمی** می‌گیرید.

| مورد | جزئیات |
|---|---|
| اپ | **Replit** — Google Play / App Store (یا فقط `replit.com` در مرورگر) |
| هزینه | پلن رایگان کافی است (اجرای عمومی و لینک موقت)؛ برای همیشه‌روشن بودن پلن پولی لازم است |
| سرعت راه‌اندازی | ۳ تا ۵ دقیقه |

### گام‌ها
1. اپ Replit را نصب و یک حساب رایگان بسازید.
2. دکمهٔ **＋ Create** ← گزینهٔ **Import from GitHub** (اگر پروژه را در GitHub گذاشته‌اید)
   یا **Upload folder / zip** و فایل `hawre-project.zip` را بدهید.
3. پروژه فایل `.replit` و `replit.nix` دارد، پس خودش Node 20 و SQLite و OpenSSL را آماده می‌کند.
4. دکمهٔ سبز **Run** را بزنید. اولین بار چند دقیقه طول می‌کشد (نصب وابستگی‌ها + ساخت دیتابیس + داده آزمایشی).
5. پنجرهٔ Webview باز می‌شود؛ روی آیکن «باز کردن در مرورگر» بزنید تا در تب کامل ببینید.

> اگر خطای Prisma دیدید، در Shell بزنید: `npx prisma generate && npx prisma migrate deploy && npx tsx prisma/seed.ts`

## 🥈 راه ۲ — GitHub Codespaces (قوی‌ترین)

**چرا؟** یک ماشین لینوکس کامل در ابر؛ VS Code داخل مرورگر گوشی. پروژه فایل `.devcontainer/devcontainer.json` دارد، پس همه‌چیز خودکار نصب می‌شود.

| مورد | جزئیات |
|---|---|
| اپ | مرورگر گوشی (Chrome/Safari) + اختیاری اپ **GitHub** |
| هزینه | ۶۰ ساعت رایگان در ماه برای حساب شخصی |

### گام‌ها
1. پروژه را در GitHub بگذارید (می‌توانم فایل zip را برای آپلود آماده کنم).
2. در اپ GitHub یا مرورگر، مخزن را باز کنید ← دکمهٔ **Code** ← تب **Codespaces** ← **Create codespace**.
3. صبر کنید تا `postCreateCommand` تمام شود (نصب، مهاجرت، داده آزمایشی).
4. در ترمینال بزنید: `npm run dev`
5. تب **PORTS** ← پورت **3000** ← **Open in Browser**. (برای باز شدن روی گوشی، Visibility را روی **Public** بگذارید.)

## 🥉 راه ۳ — اجرای واقعی روی خود گوشی (آفلاین، فقط اندروید)

**چرا؟** هیچ اینترنتی لازم نیست و همه‌چیز روی خود گوشی اجرا می‌شود. سنگین‌تر است (حدود ۱.۵ گیگابایت).

| مورد | جزئیات |
|---|---|
| اپ | **Termux** — حتماً از **F-Droid** نصب کنید (نسخهٔ Google Play قدیمی و خراب است) |
| فضا | ~۱.۵ گیگابایت |
| زمان | ۱۵ تا ۳۰ دقیقه |

> ⚠️ Prisma روی خودِ Termux (محیط Android) اجرا نمی‌شود چون موتور آن برای Android ساخته نشده. راه‌حل: یک اوبونتوی سبک داخل Termux نصب کنید.

```bash
# ۱) در Termux
pkg update -y && pkg install -y proot-distro
proot-distro install ubuntu
proot-distro login ubuntu

# ۲) داخل اوبونتو
apt update && apt install -y curl unzip openssl ca-certificates
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# ۳) پروژه را باز کنید (فایل zip را در پوشه Download گوشی بگذارید)
cd /root && unzip /storage/emulated/0/Download/hawre-project.zip && cd hawre

# ۴) اجرا
npm install
bash start.sh
```
سپس در مرورگر گوشی `http://localhost:3000` را باز کنید.

**جایگزین ساده‌تر برای همین روش:** اپ **UserLAnd** (Play Store) که مستقیم اوبونتو نصب می‌کند و نیازی به دستورهای proot ندارد؛ از گام ۲ به بعد یکسان است.
